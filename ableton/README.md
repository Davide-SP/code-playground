# Ableton – Homepage Layout Recreation

This project is a **layout recreation** of the Ableton “About” page,
built for educational purposes.

## Project brief

This exercise is based on the Frontend Practice brief:  
https://www.frontendpractice.com/projects/ableton

The goal is to recreate the overall layout and structure of the page,
focusing on visual hierarchy, spacing, and content organization
rather than pixel-perfect styling.

## Purpose

The purpose of this project is to:

- practice translating a real-world layout into HTML and CSS
- explore complex page structures and section-based layouts
- work with typography, spacing, and large visual blocks
- practice responsive layout thinking without frameworks

## Scope

- Focus on layout and structure
- Minimal styling
- No frameworks
- No JavaScript
- Non-commercial use

## Implementation Notes

- Layered image sections built using relative and absolute positioning
- Centered hero logo using transform: translate(-50%, -50%)
- Footer structured using CSS Grid

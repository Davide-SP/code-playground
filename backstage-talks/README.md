# Backstage Talks – Layout Recreation

This project is a **layout recreation** of the Backstage Talks website,
built for educational purposes.

## Project brief

This exercise is based on the Frontend Practice brief:
https://www.frontendpractice.com/projects/backstage-talks

The goal is to recreate the layout and structure of the page,
focusing on how large visual sections are organized across the viewport.

## Purpose

The purpose of this project is to:

- practice translating an existing design into code
- explore layout structure and spatial hierarchy
- work with content-driven layout decisions
- experiment with responsive behavior without frameworks

## Scope

- Focus on layout and structure
- Minimal styling
- No frameworks
- Non-commercial use

# Backstage Talks – Layout Recreation

This project is a **layout recreation** of the Backstage Talks website,
built for educational purposes.

## Project brief

This exercise is based on the Frontend Practice brief:  
https://www.frontendpractice.com/projects/backstage-talks

The goal was to recreate the overall layout and page structure,
focusing on how large visual sections are organized across the viewport
rather than on visual polish.

## Purpose

The purpose of this project was to:

- practice translating an existing design into HTML and CSS
- explore layout structure and spatial hierarchy
- understand how fixed layouts interact with scrollable content
- experiment with content-driven layout decisions
- explore scroll-based interactions using modern CSS

## What I explored

- CSS Grid for defining a fixed page frame
- Flexbox for internal alignment and spacing
- Scroll snapping to turn vertical scrolling into a sequence of full-screen sections
- Separation between fixed layout elements and scrollable content

## Scope

- Focus on layout and structure
- Minimal styling
- No frameworks
- No JavaScript for layout or interactions
- Non-commercial use

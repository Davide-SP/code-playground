# Code Playground

This repository collects a series of front-end exercises and experiments
focused on HTML, CSS, and JavaScript fundamentals.

The goal of this project is to:

- practice layout techniques (CSS Grid, Flexbox)
- improve understanding of responsive design
- translate visual designs into clean, structured code
- document learning progress in a transparent way

Each folder contains a self-contained exercise, recreated for educational purposes.

## Structure

- Each project lives in its own folder
- Projects are built without frameworks
- Focus is on layout, structure, and clarity rather than pixel-perfect design

## Disclaimer

All designs recreated in this repository are used **for educational purposes only**.
Original designs belong to their respective owners.
